# 🌱 Agricultural Intelligence

An AI-powered agricultural platform that explores the use of artificial intelligence in agriculture.

## Features
- AI integration using Google Gemini Vision API
- Agricultural intelligence solutions
- Supabase database integration
- Modern web application

## Tech Stack
- Next.js
- Google Gemini Vision API
- Supabase
- JavaScript / TypeScript (verify)

## Installation

```bash
git clone https://github.com/dishu98/Agricultural_Intelligence.git

cd Agricultural_Intelligence

npm install

npm run dev
```
